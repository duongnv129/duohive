## Before planning

- **Feature 1:**
  - A spike on OpenCode: does `opencode session list --format json` carry each session's directory, and does `--session` resume it from there?
  - Recording each running agent's CLI session id from its hooks (a store change), so a session in use by another agent can be refused.
  - Claude Code's session files are its internal format: the tested-versions list covers them.
