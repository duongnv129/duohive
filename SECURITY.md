# Security policy

## Supported versions

DuoHive is pre-1.0. Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub security advisories on this repository, or email duongnv129@gmail.com.

## Scope

- Per-launch tokens and the hook socket (`run.sock`) are in scope.
- DuoHive never modifies the user's global CLI configuration; hooks, instructions and settings are passed per launch.
